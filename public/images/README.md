# Temporary cartography artwork

`tactical-placeholder.png` was generated with OpenAI ImageGen on 18 October 2026 at the user's request for a temporary military command-station backdrop. It is original fictional survey-map artwork, not recovered geography, recorded campaign data or an authoritative tactical overlay. No proprietary map assets were copied.

The opt-in Menu control **Temporary map artwork**, or `?map=placeholder`, displays it as a presentation layer over the retained canvas. It contains no entity identifiers or operational coordinates. Disable it to inspect the real recorded map. Keep this review asset separate when integrating the cartography branch.

The source is 1672×941 pixels, approximately 3.3 MiB PNG. Its first-load transfer and blur/compositing cost are not represented by cached workspace-transition timings. Treat it as temporary; evaluate compression and larger-device rendering before shipping it as a permanent art asset.
